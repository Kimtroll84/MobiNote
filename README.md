# 모비노트 · MobiNote

마비노기 모바일의 공식 AI 커넥터를 이용하는 Windows 포터블 보조 앱입니다. 자원 채집·아이템 제작·자원 가공을 작업 대기줄로 실행하고 가공 시설을 관리합니다.

첫 공개 버전 **0.9.6** · DB 기준일 **2026.11.3** · 제작 **Troll_Kim**

## 다운로드와 실행

이 저장소의 **Releases**에서 Windows x64 포터블 ZIP을 내려받으세요. GitHub의 **Code → Download ZIP**은 개발 소스이며 실행 파일이 아닙니다.

1. ZIP 전체를 쓰기 가능한 폴더에 풀고 `MobiNote.exe`를 실행하세요. DLL과 `content` 폴더를 함께 유지하세요.
2. 게임에 캐릭터로 접속하고 AI 커넥터 기능을 켜세요.
3. **설정 → 게임 CLI 파일**에서 게임 설치 폴더의 `MabinogiMobile_CLI.exe`를 선택하고 설정을 적용하세요.
4. 상단 **연결**을 누르세요.

Windows x64, .NET Framework 4.8, Microsoft Edge WebView2 Runtime이 필요합니다. WebView2 Runtime이 없다면 [Microsoft 공식 페이지](https://developer.microsoft.com/microsoft-edge/webview2/)에서 설치하세요. 게임·공식 CLI·WebView2 Runtime은 배포본에 포함하지 않습니다. 앱 실행에 Electron·Node.js 설치는 필요하지 않습니다.

자원 가공 추가에서는 재료가 충분한 품목과 채집 후 등록 가능한 품목을 구분해 표시합니다. 채집 후 등록 가능한 품목은 황색이며, 자동 채집할 수 없는 재료가 부족하면 선택할 수 없습니다.

## 주요 기능

- 자원 채집: 목표 수량 채집, 수량 0으로 무한 채집, 낚시 지원.
- 아이템 제작·자원 가공: 횟수 지정, 채집 가능한 부족 재료 수급 후 생산.
- 가공 시설: 시설별 현황, 수령·재등록, 빈 슬롯 가공 추가, 조합을 반복하는 가공 SET.
- 작업 대기줄: 순차 실행·중단·이어서 생산·리셋, 실행 중 목록 변경 제한.
- 즐겨찾기·작업 프리셋, JSON 내보내기·불러오기.
- 소녀A/B 작업 에이전트, 별도 창·항상 위 표시, 완료·오류 알림.

상세 사용법은 [사용 매뉴얼](사용매뉴얼.md)을 확인하세요. 배포본의 `사용매뉴얼.html`은 인터넷 없이 열 수 있습니다. 최신 변경사항은 [패치노트](CHANGELOG.md)를 참고하세요.

## 데이터와 업데이트

설정·대기줄은 실행 폴더의 `settings.json`, 로그는 `diagnostics.log`·`errors.log`, 화면 캐시는 `user/`에 저장합니다.

- **덮어쓰기:** 앱을 완전히 종료하고 새 ZIP 전체를 기존 폴더에 덮어쓰세요. 개인 설정 파일과 `user/` 폴더를 유지하세요.
- **새 폴더:** 기존 앱에서 즐겨찾기·작업 프리셋을 내보낸 뒤 새 앱에서 불러오세요. CLI 경로와 앱 설정은 다시 지정하세요.

내보내기는 **즐겨찾기와 작업 프리셋만** 포함합니다. 현재 대기줄을 보관하려면 먼저 프리셋으로 저장하세요.

## 사용 시 알아둘 점

- 이 앱은 공식 CLI를 사용하는 비공식 보조 도구입니다. 게임의 확인 창은 직접 처리해야 합니다.
- 자동으로 채집할 수 없는 재료는 직접 준비해야 하며 상점 구매나 다른 레시피의 자동 연쇄 생산은 지원하지 않습니다.
- 같은 이름의 레시피는 CLI에서 번호를 지정할 수 없습니다. 재료표 선택은 수급 계산에 쓰이며 실제 실행 레시피를 보장하지 않습니다.
- 제작 도중 중단하면 부분 완료 횟수가 확인되지 않을 수 있습니다. 재개 시 실제 생산량이 목표를 넘을 수 있습니다.
- 행동 재시도 옵션은 기본 해제입니다. 켜면 추가 날개 소비나 중복 제작이 발생할 수 있으니 설정의 주의사항을 확인하세요.
- 0.9.6 자동 테스트 **246개**와 실제 C# 호스트의 모의 CLI·화면 검증을 통과했습니다. 이는 0.9.6의 장시간 실게임 검증 완료를 의미하지 않습니다. 검증 범위는 [검증 기록](VALIDATION.md)에 정리합니다.

## 개발과 빌드

현재 앱은 **C# WinForms + WebView2**입니다. 화면과 작업 엔진은 HTML/CSS/JavaScript로 구성하며 별도 Node.js 프로세스를 사용하지 않습니다.

Windows에서 Python 3, .NET Framework 4.8 개발 환경의 C# 컴파일러, WebView2 SDK가 필요합니다. 테스트에는 Node.js가 필요합니다. Python 빌드 도구는 표준 라이브러리를 사용합니다.

1. [Microsoft.Web.WebView2 1.0.4314.35 NuGet 패키지](https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.4314.35)를 내려받아 `third_party/WebView2/`에 압축 해제하세요.
2. `lib/net462/`, `runtimes/win-x64/native/`, `LICENSE.txt`가 그 폴더 아래에 있는지 확인하세요.
3. 저장소 루트에서 실행하세요.

```powershell
node --test test/*.test.cjs
python tools/build.py
```

실행 파일은 `build/MobiNote.exe`에 생성됩니다. 빌드 스크립트는 Windows 기본 Framework64 컴파일러 경로를 사용합니다. 배포 ZIP이 필요할 때는 다음을 실행하세요.

```powershell
python tools/package_portable.py
```

배포 도구는 개인 자료를 제외한 파일만 `outputs/`에 모으고 파일별 SHA-256 목록과 ZIP 해시를 생성합니다. 같은 버전의 기존 배포본은 덮어쓰지 않습니다. `tools/import_base.py`는 과거 이식 기록용이며 현재 빌드에는 필요하지 않습니다.
