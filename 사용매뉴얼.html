모비노트 사용 매뉴얼

MobiNote 0.9.6 · Windows 포터블 · 2026.11.5 개정

마비노기 모바일의 공식 AI 커넥터를 이용해 자원을 채집하고, 아이템을 제작하고, 가공 시설을 관리하는 보조 앱입니다. 이 매뉴얼은 준비 대사 통합과 중단 요청 개선이 적용된 0.9.6 실행본을 기준으로 합니다.

1. 처음 실행하기

  1. 배포 ZIP의 전체 내용을 쓰기 가능한 폴더에 풀어 주세요.
  2. 폴더 안의 MobiNote.exe를 실행하세요. 실행 파일 옆의 DLL과 content 폴더도 함께 있어야 합니다.
  3. 마비노기 모바일에 캐릭터로 접속하고 게임의 AI 커넥터 기능을 켜 주세요.
  4. 모비노트에서 설정 → 게임 CLI 파일 → 파일 선택을 누르세요.
  5. 게임 설치 폴더의 MabinogiMobile_CLI.exe를 선택하고 설정 적용을 누르세요.
  6. 상단 연결을 누르세요. 연결되면 버튼이 녹색으로 표시되고 게임 목록·보유 재료·시설 현황·날개 수량을 받아옵니다.

Windows x64, .NET Framework 4.8, Microsoft Edge WebView2 Runtime이 필요합니다. Electron이나 Node.js는 설치하지 않아도 됩니다. 게임과 공식 CLI는 모비노트에 포함되지 않습니다.

처음에는 자원 채집 탭이 열리고 즐겨찾기·작업 프리셋·작업 대기줄은 비어 있습니다. 게임 연결 전에는 등록된 기본 목록을 볼 수 있지만 실제 실행에는 연결이 필요합니다.

2. 화면과 기본 조작

위치역할
상단기능 탭, 연결, 설정
왼쪽품목·시설·프리셋 목록
가운데선택한 항목의 수량·재료·상세 설정
오른쪽작업 대기줄과 실행·중단·리셋
오른쪽 아래현재 정령의 날개 수량

품목 분류는 제목을 눌러 접거나 펼칩니다. 검색과 분류 필터를 이용해 품목을 찾을 수 있으며, 시설·프리셋 탭에는 검색창이 없습니다. 각 탭에서 마지막으로 선택한 항목은 앱을 켜 둔 동안 기억합니다. 앱을 다시 실행하면 자원 채집으로 시작하며, 작업 프리셋은 가져오기 화면으로 열립니다.

숫자 입력칸을 클릭하면 전체 숫자가 선택됩니다. 원하는 숫자를 바로 입력하거나 옆의 수량 추가 버튼을 이용하세요.

직접 실행 버튼은 선택한 작업만 바로 시작합니다. 오른쪽 대기줄에 담아 둔 다른 작업까지 실행하지 않습니다. 대기줄에 담기는 작업을 저장해 두는 버튼이며, 하단의 실행 버튼을 눌러야 시작합니다.

3. 자원 채집

  1. 자원 채집 탭의 왼쪽에서 자원을 선택하세요.
  2. 가운데에서 이번에 추가로 채집할 수량을 입력하세요.
  3. 직접 실행하거나 대기줄에 담기를 누르세요.

예를 들어 달걀을 30개 가지고 있어도 채집 수량을 10개로 지정하면, 보유량 10개를 맞추는 것이 아니라 이번 작업에서 10개를 추가로 모으는 방식입니다.

수량 0은 무한 채집입니다. 뒤에 다른 작업이 있다면 해당 채집을 중단하기 전까지 다음 작업으로 넘어가지 않습니다. 가방 공간 기준에 도달하거나 도구·소모품 등의 문제가 생겨도 종료될 수 있습니다.

낚시도 자원 채집에서 실행합니다. 모비노트가 목표 어종의 획득량을 확인해 지정 수량에 도달하면 중단을 요청합니다. 물고기가 바로 잡히지 않았다는 이유만으로 중단하지 않습니다. 게임 행동과 수량 확인 시점 때문에 실제 획득량이 목표를 조금 넘을 수 있습니다.

실행 전에는 게임의 최신 도구 상태를 확인합니다. 도구가 없거나 내구도가 부족하면 안내하며 해당 채집 작업을 건너뜁니다. 도구를 준비·수리한 뒤 다시 실행하세요.

달걀·황금 달걀 채집에서는 공격으로 중단됐다는 응답이 오면 재시도하며, 작업 에이전트에 수탉에게 맞은 횟수를 표시합니다. 앱에서 누른 중단이 우선합니다.

4. 아이템 제작과 자원 가공

탭입력 단위완료 기준
아이템 제작제작 횟수, 회제작을 마치고 결과를 받은 상태
자원 가공가공 횟수, 회등록한 가공품을 수령한 상태

회는 결과물 개수와 다릅니다. 1회에 3개가 나오는 품목을 5회 실행하면 기본 결과물은 15개입니다. 품목의 1회 생산량과 재료표를 확인해 주세요.

  1. 왼쪽에서 품목을 선택하세요.
  2. 가운데에 원하는 횟수를 입력하세요.
  3. 재료 목록의 보유·필요·부족을 확인하세요.
  4. 직접 실행하거나 대기줄에 담으세요.

게임에서 즉시 채집할 수 있는 재료가 부족하면 모비노트가 채집한 뒤 생산합니다. 드랍 및 제작, 가공으로 표시되는 재료는 직접 준비해야 합니다. 이 앱이 해당 재료를 다른 레시피로 자동 생산하거나 상점에서 구매해 주지는 않습니다.

직접 준비할 재료가 부족할 때 아이템 제작의 재료 수급 후 제작을 누르면, 가능한 횟수만 제작할지 묻습니다. 대기줄에서는 질문 없이 생산 가능한 횟수만 수행하며, 0회라면 해당 작업을 건너뛰고 다음으로 진행합니다. 필요한 채집량도 실제 가능한 생산량에 맞춰 계산합니다.

부족·축소·건너뜀 상태의 대기줄 버블은 적색 계열로 표시됩니다. 재료를 보충한 뒤 다시 실행할 수 있습니다.

같은 이름의 재료표가 여러 개일 때

가운데에 재료표 탭과 ? 안내가 나타납니다. 자원 가공에서는 선택한 재료표로 재료 수급량을 계산하고, 대기줄·프리셋에도 그 선택을 저장합니다.

다만 공식 실행 명령은 품목명으로 생산을 요청합니다. 게임은 제작 가능한 동명 레시피 중 목록에서 앞선 것을 사용하므로, 재료표를 선택했다고 게임의 실행 레시피까지 지정되는 것은 아닙니다. 가공 진행률의 전체 시간은 같은 이름 중 짧은 레시피를 기준으로 계산합니다.

5. 가공 시설 현황과 수령

가공 시설 → 전체 가공 시설에서 6개 시설을 한눈에 볼 수 있습니다.

각 카드 위쪽의 진한 영역은 시설명과 완료·가공·대기 건수, 아래쪽은 등록된 가공품과 남은 시간입니다. 같은 품목·상태는 묶어 표시하며 항목이 많으면 외 N종 보기로 확인합니다. 카드를 누르면 왼쪽 목록에서 시설을 선택한 것처럼 해당 시설의 상세 화면이 열립니다.

시설의 남은 시간은 연결된 동안 주기적으로 받아오고, 그 사이에는 화면에서 1초씩 줄여 표시합니다. 시간이 0이 되어도 게임의 완료 응답을 받기 전까지는 완료 확인 중으로 보일 수 있습니다.

버튼동작
일괄 수령선택한 시설의 완료품을 받습니다. 전체 화면에서는 여러 시설을 처리합니다.
수령 후 재등록완료품을 받은 뒤, 받은 가공 건을 다시 등록합니다. 계속 반복하는 SET과는 다릅니다.
자원 가공 추가선택한 시설의 빈 슬롯에 가공을 등록할 목록을 만듭니다.

수령 중에는 진행 안내만 표시하고, 확인된 수령 품목과 가공 건수는 실행이 끝난 뒤 최종 결과에 모아 표시합니다. 기존부터 시설에 등록되어 있던 가공품도 포함하며, 건수는 결과물 개수와 다를 수 있습니다.

수령은 시설 단위입니다. 한 품목의 완료품만 따로 고르는 방식이 아니므로, 같은 시설의 다른 완료품도 함께 수령될 수 있습니다.

6. 자원 가공 추가 — 한 번 등록하기

이 기능은 슬롯에 가공을 걸어 두고 다른 일을 하려는 경우에 사용합니다.

  1. 개별 시설에서 자원 가공 추가를 누르세요.
  2. 팝업 위쪽 가공품 목록에서 품목을 선택하세요.
  3. 같은 품목을 여러 번 누르면 아래 선택 버블이 ×3처럼 묶입니다. 선택 버블을 누르면 1건씩 뺍니다.
  4. 즉시 이동하여 등록 또는 대기줄에 담기를 누르세요.

선택할 때마다 앞서 선택한 품목이 사용할 재료를 빼고 다시 계산합니다. 재료가 충분한 품목은 바로 선택할 수 있고, 채집으로 보충할 수 있는 품목은 황색으로 표시됩니다. 실행하면 부족한 재료를 채집한 뒤 등록합니다. 자동 채집할 수 없는 재료가 부족한 품목은 선택할 수 없습니다.

완료 슬롯도 등록 가능한 자리로 계산하며, 등록 전에 완료품을 수령합니다. 선택 수는 등록 가능한 슬롯 수를 넘을 수 없습니다.

이 기능으로 만든 작업은 등록이 끝나면 완료됩니다. 완제품이 나올 때까지 기다렸다가 수령하는 자원 가공 탭의 작업과 다릅니다. 반복하려면 아래의 가공 SET을 이용하세요.

7. 가공 SET — 일정한 조합 반복하기

  1. 개별 시설 아래의 가공 SET 제작 → 가공품 선택을 누르세요.
  2. 아래쪽 품목 버블을 원하는 횟수만큼 누르세요. 위쪽 SET 영역에 선택한 조합이 표시됩니다.
  3. 선택 완료를 누르세요.
  4. 반복 횟수와 재료 부족 시 재료 채집 횟수를 정하세요.
  5. 대기줄에 담기를 누르세요.

반복 1회는 선택 목록을 한 바퀴 수행하는 단위입니다. 예를 들어 강철괴 ×6, 합금강괴 ×1을 선택하고 반복 3회를 지정하면 강철괴 가공 18건과 합금강괴 가공 3건을 등록·수령합니다. 결과물 개수는 각 품목의 1회 생산량에 따라 달라집니다.

선택 조합이 7건보다 적으면 조합을 반복해 시설 슬롯을 채우되, 유한 반복의 남은 목표를 초과해서 등록하지 않습니다. 반복 횟수 빈칸 또는 0은 무한 반복입니다.

재료 부족 시 재료 채집

기본값은 10회입니다. SET 전체 10바퀴가 아니라 부족한 품목을 10건 가공할 분량을 뜻합니다. 남은 목표가 더 적거나 직접 준비 재료가 제한되면 그 범위까지만 준비합니다.

예를 들어 A와 B 중 A의 재료만 부족하고 이 값을 2로 정했다면, A 2건분의 부족한 채집 재료를 모읍니다. 값이 0이면 SET을 위해 추가 채집하지 않으며, 재료가 떨어지면 추가 등록을 멈추고 이미 등록한 가공품을 수령해 마무리합니다.

채집할 수 없는 재료가 부족해도 가능한 범위까지만 진행합니다. 무한 SET을 넣은 대기줄은 SET이 끝나지 않는 동안 전체 완료 상태가 되지 않습니다.

8. 작업 대기줄의 실행 순서

대기줄은 단순히 위에서 아래로 한 번만 읽는 방식에 시설 관리가 더해져 있습니다.

  1. 시작 시 보유 재료로 가공 시설에 먼저 등록할 수 있는 작업을 처리합니다.
  2. SET과 일반 생산에 필요한 부족한 채집 재료를 준비합니다. 공통 재료는 SET에 먼저 배정합니다.
  3. SET을 등록하고 일반 작업을 순서대로 수행합니다.
  4. 일반 작업 버블 하나를 진행하는 동안에는 SET의 수령·재등록 때문에 작업을 끊지 않습니다.
  5. 일반 작업이 끝나면 시설의 완료품을 수령하고 다음 가공을 등록합니다.
  6. 자원 가공이 슬롯이나 완료를 기다려야 하면 다음 일반 작업으로 넘어가며, 이후 다시 확인해 계속 진행합니다.

시설에 아무 가공이나 존재한다고 모두 자동 수령하지는 않습니다. 대기줄에서 관리하는 시설 작업과 수령 명령에 따라 처리합니다.

작업을 실행하는 동안에는 추가·삭제·비우기·드래그 순서 변경·프리셋으로 대기줄 교체가 제한됩니다. 변경하려면 먼저 중단하세요. 정지 상태에서는 버블을 드래그해 순서를 바꾸고 삭제할 수 있습니다. SET 버블은 별도 색상으로 상단에 표시됩니다.

버튼동작

이어서 생산하기중단·오류로 멈춘 작업의 기록을 유지하고 남은 작업을 진행합니다.
다시 실행완료된 대기줄을 원래 지정한 수량·횟수로 새로 시작합니다.
리셋품목·목표·순서는 유지하고 진행 기록을 초기화합니다. 자동 실행하지 않습니다.
중단현재 실행을 멈춥니다.

중단 버튼은 한 번 누르면 됩니다. 요청이 일시적으로 실패하거나 종료가 확인되지 않으면 앱이 필요한 중단 요청을 다시 보냅니다. 게임의 확인 창이 막고 있으면 해당 창을 직접 처리해 주세요. 이는 생산을 다시 시작하는 자동 재시도 옵션과는 별개의 동작입니다.

재료 부족으로 건너뛴 작업은 이어가기 대상으로 되살리지 않습니다. 완료와 건너뜀만 남으면 다시 실행이 됩니다. 오류로 실행 결과가 불확실한 작업은 게임 상태 확인과 리셋을 요구할 수 있습니다.

리셋해도 게임 시설에 이미 등록된 가공은 취소되지 않습니다. 기존 등록분은 새 목표 횟수에서 제외됩니다. 진행 중 가공을 취소하려면 게임에서 직접 처리해야 합니다.

9. 즐겨찾기와 작업 프리셋

즐겨찾기

왼쪽 품목 옆의 별을 누르면 색이 들어오며 즐겨찾기로 등록됩니다. 각 탭의 별 필터로 해당 탭의 즐겨찾기만 볼 수 있습니다.

즐겨찾기 탭에서는 자원 채집·자원 가공·아이템 제작의 즐겨찾기를 함께 보여줍니다. 카테고리 없이 등록 순서로 표시하며, 선택한 항목의 원래 기능으로 실행합니다.

작업 프리셋

  1. 오른쪽 대기줄에 자주 사용할 작업을 담으세요.
  2. 작업 프리셋 탭에서 현재 대기줄을 가져와 새 프리셋을 만드세요.
  3. 이름을 정하고 필요하면 수량·횟수·순서·항목을 수정하세요.
  4. 저장을 누르세요.

상단 대기줄에서 가져오기는 현재 대기줄을 프리셋 편집창으로 가져옵니다. 기존 편집 내용이 있으면 교체 여부를 묻습니다. 새 프리셋 생성도 현재 대기줄을 바탕으로 새 프리셋을 만듭니다.

저장된 프리셋을 고르고 하단 대기줄에 등록을 누르면 현재 대기줄 전체를 해당 프리셋으로 교체합니다. 기존 대기줄에 이어 붙이지 않으며 자동 실행하지도 않습니다.

수정한 내용이 없으면 저장이 비활성화됩니다. 저장하지 않고 다른 화면으로 이동할 때는 저장·변경 취소·계속 편집 중에서 선택합니다.

10. 설정

설정사용 방법
게임 CLI 파일게임 설치 폴더의 MabinogiMobile_CLI.exe를 선택합니다.
가방 공간체크하면 지정 사용률 이상에서 작업을 중단합니다. 기본값은 95%입니다.
행동이 중단되었을 때 다시 작업 시도기본 해제. 켜면 중단·창 차단 응답 후 기다렸다가 다시 요청합니다. ?에서 주의사항을 확인하세요.
판타지 라이프 토탈 멤버십 적용기본 체크. 해제하면 가공 진행률 계산에 쓰는 전체 시간을 2배로 봅니다. 게임이 반환한 실제 남은 시간은 바꾸지 않습니다.
가공 SET 최대 반복 시간 설정체크하고 분을 입력하면 SET의 추가 등록 시간을 제한합니다. 기본은 체크 해제, 시간 제한 없음입니다.
작업 에이전트 선택소녀A는 존댓말, 소녀B는 활발한 반말을 사용합니다. 기능은 같습니다.
별도 팝업으로 표시체크하면 자유롭게 옮길 수 있는 별도 창으로 표시하고 위치를 기억합니다. 해제하면 앱 가운데에 표시합니다.
가장 위에 표시별도 팝업일 때만 설정할 수 있습니다. 별도 팝업과 가장 위 옵션은 기본 체크입니다.
데이터 관리즐겨찾기와 작업 프리셋을 내보내거나 불러옵니다.

설정을 바꾼 뒤 설정 적용을 누르세요. 실행 중에는 설정을 바꿀 수 없습니다.

자동 재시도는 약 5초 간격으로 요청하며, 인벤토리가 닫혔는지 직접 판별하는 기능은 아닙니다. 게임에서 직접 멈춘 행동도 다시 시작할 수 있고, 매번 날개가 추가로 소비될 수 있습니다. 제작 일부를 마친 뒤 중단하면 완료 횟수를 확인할 수 없어 중복 제작될 수 있습니다. 앱에서 중단하면 재시도하지 않으며, 통신 오류 등으로 실행 결과가 불확실하거나 시설 구성이 바뀐 경우에도 자동 재시도하지 않습니다.

가방 공간 기준은 개별 작업을 건너뛰는 조건이 아니라 현재 실행을 중단하는 조건입니다. 공간을 확보한 뒤 다시 진행하세요.

SET 시간 제한은 일반 채집·아이템 제작·자원 가공에 적용되지 않습니다. 한도에 도달하면 SET을 새로 등록하지 않고 이미 등록한 가공품은 수령까지 마칩니다. 따라서 전체 실행 종료 시각이 설정한 시간과 정확히 같지는 않을 수 있습니다.

11. 작업 에이전트와 알림

실행하면 하나의 작업 에이전트 창에서 재료 준비·채집·제작·가공 등록·대기·수령·오류 상태를 계속 보여줍니다. 채집 카운터는 현재 보유량이 아니라 이번 작업에서 모은 양입니다.

작업 에이전트 전체 창의 크기는 고정이며, 버블 높이만 대사량에 맞춰 바뀝니다. 하단에는 상태 | 완료 N/M과 중단·닫기 버튼이 표시됩니다. 짧게 지나간 일반 대사는 직전 한 줄만 함께 남기며, 채집 카운터·가공 진행 정보·종료 보고에는 이전 대사를 섞지 않습니다. 충분히 오래 표시된 대사는 다음 대사와 함께 남기지 않습니다. 긴 결과는 버블 내부에서 스크롤합니다.

단일 작업의 준비 안내에는 품목과 목표 수량이 표시됩니다. 채집 목표를 모으면 마지막 수량을 유지한 채 채집 마무리를 안내합니다. 일시적으로 게임 정보를 다시 확인할 때는 진행 대사를 유지하고 하단 상태로 표시합니다. 로딩이나 게임 확인 창에는 별도 안내가 나옵니다.

별도 창에서는 버튼을 제외한 소녀 그림·말풍선·배경·하단 영역을 드래그해 이동합니다. 마지막 위치를 기억하며, 실행 중에는 실수로 닫지 못하도록 닫기를 제한합니다. 완료·중단 후에는 닫을 수 있습니다. 상단에 작업 에이전트 버튼이 보이면 진행 창을 다시 열 수 있습니다.

전체 실행이 끝나면 완료 알림음을, 오류로 끝나면 중단 알림음을 재생합니다. 사용자가 중단한 경우에는 소리가 나지 않습니다. 개별 가공품을 한 번 수령할 때마다 전체 완료음을 내지는 않습니다.

게임의 AI 커넥터 이용 확인 창을 감지하면 알림음을 한 번 내고 기다립니다. 게임에서 직접 확인을 눌러 주세요. 차단이 해소되고 상태 확인이 끝나면 이어서 진행합니다. 로딩·인벤토리 등의 일시적인 차단도 대기 후 복구를 시도하지만, 모든 오류가 자동 복구되는 것은 아닙니다.

12. 정보 갱신과 날개 표시

상단 연결은 연결된 상태에서 다시 눌러도 됩니다. 목록·보유 재료·시설·날개 정보를 다시 받아옵니다. 실행 중에는 전체 연결 갱신이 제한됩니다.

오른쪽 아래의 날개 숫자를 누르면 날개만 다시 조회합니다. 날개는 연결·수동 조회·실행 종료 때 갱신하며 실행 중 매초 조회하지 않습니다.

대기줄의 날개 표시는 작업에 따른 예상 비용입니다. 실제 재료 상태·재시도·게임 처리에 따라 달라질 수 있으며, 무한 반복은 총비용을 유한한 숫자로 정하지 않습니다. 현재 보유 날개와 예상 비용은 서로 다른 값입니다.

품목 목록의 보유량 —는 0개가 아니라 조회로 확인하지 못한 상태입니다. 일부 장비 등은 공식 보유 아이템 조회 대상에 포함되지 않습니다.

13. 백업·복원·업데이트

백업하기

작업을 중단한 뒤 설정 → 데이터 관리 → 내보내기를 누르세요. 파일명에 날짜가 붙은 JSON 파일로 즐겨찾기와 작업 프리셋을 저장합니다.

현재 작업 대기줄, 진행 기록, CLI 경로, 앱 설정은 이 내보내기에 포함되지 않습니다. 대기줄 구성을 보관하고 싶다면 먼저 작업 프리셋으로 저장한 다음 내보내세요.

복원하기

설정 → 데이터 관리 → 불러오기에서 모비노트가 만든 JSON을 선택하고 교체를 확인하세요. 즐겨찾기와 작업 프리셋을 파일의 내용으로 교체합니다. 현재 대기줄과 앱 설정은 그대로 유지됩니다. 현재 버전에 없는 품목이 포함돼 있으면 복원이 거절될 수 있으므로 앱 버전을 확인하세요.

업데이트하기

같은 폴더에 덮어쓰기: 앱을 완전히 종료하고 새 ZIP 전체를 기존 실행 폴더에 덮어쓰세요. 개인 설정 파일과 사용자 폴더는 남겨 두세요.

새 폴더에서 시작: 먼저 즐겨찾기·프리셋을 내보내고, 새 ZIP을 별도 폴더에 푼 뒤 불러오세요. CLI 경로와 앱 설정은 새 폴더에서 다시 지정합니다. 프리셋을 대기줄에 등록해 작업 구성을 복원할 수 있습니다.

설정·현재 대기줄·진행 기록은 실행 폴더의 settings.json, 로그는 diagnostics.log / errors.log, 화면 캐시는 user 폴더에 저장됩니다. 폴더 전체를 보관하면 이 파일들도 함께 보관됩니다. 실행 중인 작업의 상태까지 다른 PC에서 그대로 이어갈 수 있다고 보장하는 백업은 아닙니다.

14. 문제가 생겼을 때

상황확인할 것
실행되지 않음ZIP 전체를 풀었는지, DLL·content 폴더가 있는지, 필요한 실행 환경이 설치됐는지 확인하세요.
연결되지 않음실제 캐릭터 접속·로딩 완료·AI 커넥터 설정·선택한 CLI 파일을 확인하세요.
도구 안내 후 채집을 건너뜀해당 도구와 내구도를 확인하고 준비·수리 후 다시 실행하세요.
재료는 있는데 생산 가능량이 낮음잠금 여부, 창고 사용 가능 여부, 이동 비용, 선택한 동명 재료표를 확인하세요.
적색 버블이 생김부족한 직접 준비 재료를 채우거나 목표를 줄이세요. 다른 가능한 작업은 계속 진행될 수 있습니다.
완료 확인 중이 오래 유지됨화면 예상 시간이 아니라 게임의 완료 응답을 기다리는 상태일 수 있습니다. 게임 시설 현황과 연결을 확인하세요.
연결이 잠깐 끊기거나 요청 대기 안내가 나옴일시적인 오류는 재시도합니다. 중단하려면 앱의 중단 버튼을 누르세요.
실행 결과 확인 불가 안내가 나옴게임에서 실제 생산·등록 상태를 확인하세요. 중복 실행을 막기 위해 재시작이 제한될 수 있습니다. 리셋은 진행 기록을 초기화합니다.

제작 도중 중단된 일부 횟수는 CLI 응답만으로 정확히 집계되지 않을 수 있습니다. 이런 경우 화면의 완료 횟수가 실제 결과물과 다를 수 있으므로 게임 보유량을 확인하세요. 가공 시설의 슬롯을 게임에서 직접 취소·변경하면 모비노트가 해당 시설의 소유 작업을 확인하지 못해 그 시설만 보류할 수 있습니다.

문제 확인을 요청할 때는 발생 시각, 품목명, 직접 실행인지 대기줄인지, 누른 버튼, 게임에서 실제로 일어난 일을 함께 알려 주세요. 실행 폴더의 로그와 대조하면 원인을 찾기 쉽습니다.

앱 왼쪽 위 소녀 아이콘을 누르면 버전·DB 날짜·제작자·구성요소 정보를 확인할 수 있습니다.
